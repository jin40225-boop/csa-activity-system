# 活動與教育訓練系統（A 系統）— 軟體原型

兒少性不當對待防治方案的「宣導・親職・教育訓練」辦理系統。
放在 NAS 共用資料夾，三個帳號（一位督導、兩位社工）可同時開啟、同時登打，資料自動同步。

> 狀態：**原型 v0.1**（2026-10-19）。功能與畫面大致完成；權限、表單欄位、領據與報告書正式範本待後續提供資料後特化。

## 給使用者

- 每人用自己名字的捷徑開啟：`啟動＿活動與教育訓練系統＿督導／社工一／社工二`。不用登入。
- 主要頁面「場次管理」：左邊是場次清單（每場三顆燈：場地／協辦／講師），右邊是這一場的一站式頁面。
  - 第一排快速選項：編輯場次、場次資料夾、異動紀錄、取消場次。
  - **第二排大按鈕（寫出狀態）**：出席與回饋、活動照片、講師領據、場次結案——點了開浮動視窗就地完成。
  - 三方確認：記錄電話 → 寄確認信（公版自動帶入，用 Outlook 寄出或複製內容）→ 記錄回覆。逾期自動標紅、可寄提醒。
- 其他頁：總覽（年度目標）、成果報告書（產生、改字、切換圖表、下載 Word）、名冊、信件總覽、設定（書信公版、權限、帳號、參數、範本資料夾）。

## 架構（沿用第三次管理系統／微旅 v2 已在 NAS 驗證的做法）

| 層 | 做法 |
|---|---|
| 程式 | C# .NET 10、WinForms＋WebView2；畫面是原生 JS（設計規格 v1＋cms-kit 浮動視窗） |
| 資料 | NAS 上一顆 SQLite：DELETE journal（不用 WAL）、busy_timeout 15 秒、每次短連線、`ver` 欄樂觀鎖、`change_log` 留痕 |
| 同步 | 畫面每 6 秒問一次最新異動序號（設定可改），變了就重讀；切回視窗立即檢查；別人剛改了什麼會跳提示 |
| 衝突 | 兩人同時改同一筆：後存的人被擋下並告知「剛被誰在何時改過」，不會默默蓋掉 |
| 權限 | 集中在 `Store.Can`，規則存在設定（每個動作：所有人／只有督導），督導在「設定 → 權限」改，不必改程式 |
| 檔案 | 照片、簽到表、回饋單掃描檔、領據存在 `資料\附件\場次編號\類別\`；原檔不動 |
| 範本 | `範本\講師領據.docx` 用 `{{佔位字}}` 填值（換檔即換版型）；書信公版在設定頁編輯；成果報告書由系統排版輸出 Word |
| 寄信 | 產生待寄信件（.eml）用電腦的郵件程式開啟，按傳送即寄出；系統記錄寄出時間並追蹤回覆期限 |
| 備份 | 每天第一次開程式時 `VACUUM INTO` 一份到 `備份\`，留 30 天＋每月 1 號 |
| 部署 | 資料夾形式發行（不用單一 exe）、本機快取啟動器、WebView2 資料夾在 `%LOCALAPPDATA%`、部署後從 NAS 實跑 `--selftest` |

## NAS 上的資料夾

```
活動與教育訓練系統\
  程式\            ← 部署腳本複製過來（不要手動改）
  資料\activity.db  資料\附件\
  範本\講師領據.docx  範本\範本說明.txt
  備份\
  啟動器.ps1   啟動＿活動與教育訓練系統＿督導.lnk（社工一、社工二）
  版本與部署紀錄.md
```

## 開發

```powershell
dotnet build
.\部署\本機試用_三個帳號.ps1 -Reset      # 本機模擬 NAS，同時開三個帳號
src\ActivitySystem.App\bin\Debug\net10.0-windows\ActivitySystem.exe --selftest --user worker1
```

- 自動驗收：`--script 步驟.json`（在畫面執行 JS、截圖、寫 `結果.json` 後自動結束）；`ACTIVITY_PICK`（以 `|` 分隔的檔案，代替選檔視窗）、`ACTIVITY_EXPORT_DIR`（存檔不跳視窗）、`ACTIVITY_LOCAL_DIR`（換本機資料夾）。
- 部署：`.\部署\部署到NAS.ps1`（第一次加 `-Init`）。**只在負責人說要部署時執行。**
